# Skiller Guard

RuneLite plugin for skillers. Keeps risky menu options hidden without relying on Menu Entry Swapper custom hides or separate RuneLite profiles.

## Status

Scaffold only — features are being designed and implemented.

## Planned

- Always-on plugin with manual enable and optional auto level-3 detection
- Categorised menu hides (prayer XP, combat misclicks, NPCs, spells, etc.)
- Future skiller-account safety features

## Development

Requires JDK 11+.

```bash
./gradlew run
```

For Jagex accounts, follow [Using Jagex Accounts](https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts).
